> **Table design template** — used for files `docs/<problem-name>/design/<schema>.<table>.md`.
> This format is **identical to table info files in `catalog/`** (files generated by `build_catalog.py`).
> Keep section structure, headings, tables, code blocks unchanged; only replace `<placeholder>` values.

## ABI

### <abi_name>

#### `<EventName(indexed type param, ...)>` — event

```json
{
  "anonymous": false,
  "inputs": [
    {
      "indexed": true,
      "name": "<param>",
      "type": "<type>"
    }
  ],
  "name": "<EventName>",
  "type": "event"
}
```

#### `<functionName(params) returns (type)>` — view function

```json
{
  "constant": true,
  "inputs": [],
  "name": "<functionName>",
  "outputs": [
    {
      "name": "",
      "type": "<type>"
    }
  ],
  "payable": false,
  "stateMutability": "view",
  "type": "function"
}
```
